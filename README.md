# Landing Page

A landing page built for [The Odin Project](https://www.theodinproject.com/) Foundations course (HTML/CSS).

## Built with

- HTML5
- CSS3 (Flexbox)
- [Roboto](https://fonts.google.com/specimen/Roboto) via Google Fonts

## Sections

Header and hero, information cards, quote, call to action, and footer.
